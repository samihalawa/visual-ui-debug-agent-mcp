# Changelog

All notable changes to VUDA are documented here.

## [1.1.0] - 2026-08-11

- Added one shared browser runtime for local Playwright, Browserbase, Anchor Browser, and direct CDP connections.
- Added `.env` loading, cookie injection, local storage-state persistence, Browserbase Context reuse, and Anchor profile configuration.
- Added a credential-safe `browser://status` MCP resource and deterministic provider lifecycle tests.
- Fixed `sitemap_crawler` failing when it was the first browser tool called.

## [1.0.3] - 2026-08-11

- Fixed the broken architecture diagram and corrected the tool count in the banner.
- Replaced the typo-filled workflow mockup with an accurate capabilities graphic.
- Removed unused and duplicate media assets.
- Added current contribution, issue, pull request, conduct, and security guidance.
- Marked generated distribution files correctly for GitHub language statistics.
- Strengthened automated tests, dependency maintenance, and release workflows.

## [1.0.2] - 2025-12-09

- Added workflow validation, screenshot, and visual debugging improvements.

## [1.0.1] - 2025-06-19

- Published the initial npm package updates.
